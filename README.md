# Cheng Kelo Fish Website

A multi-page static website for Cheng Kelo Fish — located at Anaka Town Council, Opposite Kiza Enterprise, Room 18.

## 🚀 Deploy to GitHub Pages (Free Hosting)

### Step 1 — Create a GitHub account
Go to [github.com](https://github.com) and sign up for free if you don't have an account.

### Step 2 — Create a new repository
1. Click the **+** icon → **New repository**
2. Name it: `cheng-kelo-fish` (or any name you like)
3. Set it to **Public**
4. Click **Create repository**

### Step 3 — Upload your files
1. On the repository page, click **Upload files**
2. Drag and drop ALL files and folders from this `cheng-kelo-fish` folder:
   - `index.html`, `about.html`, `products.html`, `services.html`, `gallery.html`, `videos.html`, `contact.html`
   - `css/` folder
   - `images/` folder (with your logo.png, fish photos, hero.jpg)
   - `videos/` folder (optional)
3. Click **Commit changes**

### Step 4 — Enable GitHub Pages
1. Go to **Settings** tab of your repository
2. Scroll to **Pages** in the left sidebar
3. Under **Source**, select **Deploy from a branch**
4. Set branch to **main** and folder to **/ (root)**
5. Click **Save**

### Step 5 — Your site is live!
After ~1 minute, your website will be available at:
```
https://YOUR-GITHUB-USERNAME.github.io/cheng-kelo-fish/
```
